Node lives here after SETUP-RUNTIME.bat (Windows) or setup-runtime.command
(Mac) has been run once on a computer with internet.

  win-x64/node.exe      Windows
  darwin-arm64/node     Apple Silicon Macs (M1 and later)
  darwin-x64/node       Intel Macs

These folders are empty until then. The Game Grid still works without
them on Windows - it falls back to PowerShell.
